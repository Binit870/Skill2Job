# mp-frontend

The Skill2Career web app — student portal, recruiter portal, and public marketing site. React 19 + Vite + Tailwind CSS.

See the [project root README](../README.md) for full documentation: architecture, environment variables, features, design system, and API reference.

## Quick start

```bash
npm install
cp .env.example .env   # set VITE_API_URL
npm run dev             # http://localhost:5173
npm run build            # production build → dist/
```
