# mp-backend

The Skill2Career API — Express + MongoDB. Owns auth, all application data, file storage, email, and proxies ML-backed features to `ml-service`.

See the [project root README](../README.md) for full documentation: architecture, environment variables, features, security model, and API reference.

## Quick start

```bash
npm install
cp .env.example .env   # see root README for what each variable does
npm run dev             # nodemon, http://localhost:5000
npm start                 # production
```
